**练度门槛**：`精N` = 精英化 N 阶段；`Lv.30` = 等级 30（一至三星干员满级即解锁，不需要精英化）。

**提升 vs 解锁 —— 这个区分很关键**（文案与游戏内、与 RIIC-Web 干员查询页一致）：

- `初始解锁` / `精英 N 解锁` / `等级 N 解锁` = **新增一个技能，之前的继续生效**（并存）
- `精英 N 提升` = **替换掉前一档，只有新的生效**（已标注替换谁）

例：温蒂精 2 的「仿生海龙」是**提升**，替换精 0 的「自动化·β」，所以只按 +15%/电站 算，不是 10%+15%；巫恋精 2 的「低语」是**解锁**，精 0 的「裁缝·α」仍然在，两个同时生效。
