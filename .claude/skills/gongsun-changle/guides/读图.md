# 读图

## 通则

**允许读错，不允许闷头猜。**

- 读到的关键数值**先回述成表请用户确认**，再下判断
- 看不清的项**明确说出来**请用户补，不要填一个「看着合理」的值
- 截图压缩、分辨率低、卡片被遮挡都很常见，问一句的成本远低于结论错了

## 三类截图，策略不同

| 类型 | 信息密度 | 策略 |
|------|---------|------|
| 干员 box 列表 | 高，让用户逐个打字不现实 | **尽力读**，读不清的单独问 |
| 基建简报 | 中，字段少但数值精度要求高 | **读完必须回述确认** |
| 设施面板 | 低，**且诊断所需的关键信息不在图里** | **直接列清单要**，图只用来确认已有字段 |

第三类要特别注意：条件型技能的判定常常依赖**其他房间、其他设施、甚至副手位**的状态。
再强的视觉能力也读不出来——所以不要尝试从图里推，直接问。

## 干员 box 卡片

每张卡上与基建有关的五个字段：

| 字段 | 位置 | 读法 |
|------|------|------|
| 职业 | 左上角图标 | 8 职业之一 |
| 稀有度 | 职业图标右侧 | 星星数 1–6 |
| **精英化** | **左侧中偏下，带尾巴的 V 形标记** | **无 = 精0，一层 = 精1，两层叠 = 精2** |
| 等级 | 左下圆圈 LV | 数字 |
| 名字 | 底部 | 用于查 `references/名册.md` |

### 精英化直接读卡面，不要从等级猜

精英化之后**等级重置为 1**，所以 `LV1` 既可能是刚抽到的白板，也可能是刚精二。
但 V 形标记不受影响——直接读它。

### 解锁条件不用记规则

读到「稀有度 + 精英化 + 等级」之后，去 `references/技能-<设施>.md` 比对：
每条技能都标了自己的门槛（`精0` / `精1` / `精2` / `Lv.30`）。

- 一至三星有 16 条技能门槛是 `Lv.30` 而非精英化——**低星必须同时看等级**
- 大多数干员的第二个基建技能在 `精2` 解锁，且**精 2 的 1 级即可**，不需要练满级

### 回述格式

```
我从图里读到（请确认）：
- 巫恋 ☆5 精2 LV1
- 温蒂 ☆6 精1 LV80
- 卡涅利安 ☆6 精0 LV1
看不清精英化标记的：止颂、水月 —— 这两个麻烦你说一下练度
```

## 基建简报

字段口径见 `guides/基建物流链.md` 的「简报字段属于哪一侧」。要点：

- **制造侧**（作战记录 EXP 值、贵金属价值）和**贸易侧**（龙门币、合成玉）是上下游，**不能相加**
- 玩家说的「总产能」通常指制造侧合计
- 合成玉 0 只说明没走开采协力策略，不是没产出
- 时钟那组数（39h / 42h 之类）语义未确认，**不要基于它下结论**

### 回述格式

```
我从简报里读到（请确认）：
| 项 | 5.17 | 5.18 | 5.19 |
| 中级作战记录 | 34 | 33 | 34 |
| 赤金 | 90 | 93 | 90 |
| 龙门币 | 64100 | 67900 | 63400 |
| 订单数 | 37 | 41 | 37 |
```

## 设施面板

图里通常只能看到：设施类型与编号、站等级、订单进度、在岗人数、
面板上的效率与心情消耗汇总、谈判策略。

**图里看不到、但诊断必需的**：

- 在岗三人**分别是谁**、各自精英化（头像常认不出）
- 条件型技能依赖的**其他房间状态**（某派系干员在哪、有几个、是否为副手或在活动室）
- 其他设施的数量与产物分配（几间制造站在产赤金）

所以处理方式是**列一份具体的、可逐条回答的清单**，而不是笼统问「你基建怎么配的」。
清单每一项都要能直接映射到某个技能条件。

### 清单示例（以「为什么鸿雪体系只有 60%」为例）

```
图里能看到：贸易站 Lv.3、订单 0/10、三人在岗、面板 +3% / +60%、策略龙门商法。

要判断这个数值对不对，还需要你确认几件事：
1. 站内三人分别是谁、各自精几？
2. 基建内一共有几名杜林族干员（至简/桃金娘/褐果/杜林/特克诺）？
3. 这些杜林族里，有没有被设为副手、或正在活动室？（这两种不计入）
4. 有几间制造站正在生产赤金？
```
